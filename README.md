## 🚀 Projeto em destaque

### 🎓 CRM Gestão Escolar

Sistema full stack desenvolvido para centralizar processos administrativos de uma instituição de ensino.

O projeto surgiu a partir de necessidades reais de gestão e foi transformado em uma aplicação web com diferentes módulos e níveis de acesso.

**Principais funcionalidades:**

- Gestão de interessados e acompanhamento de atendimento
- Matrículas e responsáveis
- Contratos
- Controle financeiro
- Usuários e diferentes perfis de acesso
- Auditoria de operações
- Monitoramento de sessões ativas
- Recuperação e alteração segura de senhas
- Backup e restauração de dados
- Geração de documentos em PDF
- Utilização em rede local

**Tecnologias:**

`JavaScript` `Node.js` `Express` `PostgreSQL` `HTML5` `CSS3` `Git`
